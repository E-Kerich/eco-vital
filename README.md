# Eco-Vital Consulting Platform

A full-stack consulting platform built with React, Node.js, Express, MongoDB, and Tailwind CSS.

## Features

- Admin Dashboard (JWT Protected)
- Blog CMS with TipTap Editor
- Cloudinary Image Uploads
- Lead Capture System
- Paystack Payment Integration
- Email Notifications via Resend
- Analytics Dashboard
- Public SEO-Friendly Blog Pages

---

## Tech Stack

### Frontend
- React + Vite
- Tailwind CSS
- Axios
- TipTap Editor

### Backend
- Node.js + Express
- MongoDB (Mongoose)
- JWT Authentication
- Paystack API
- Resend Email Service
- Cloudinary
